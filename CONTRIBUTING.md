# Contributing

Thanks for taking a look at hbtop.

## Before opening a PR

- Open an issue or discussion for non-trivial changes.
- Keep the scope small and explain the motivation.
- Run `go build ./...` and `go vet ./...`.
- Match the existing Go style and keep collectors side-effect free.

## Areas that need help

- macOS and Windows collectors.
- More GPU backends (NVIDIA / Intel).
- Better leaderboard presentation and attract animations.
- `.branim.json` example animations.
- Documentation and screenshots.

## AI-generated code

Be transparent about AI assistance in the PR description. You are responsible
for understanding and maintaining anything you submit.
